Publishing to PyPI is automated. Merging dev into main triggers
.github/workflows/release.yml, which tags the release, creates the GitHub
release, and publishes to PyPI. See the "Pushing to the repository main branch"
section of CONTRIBUTING.md.

Do not publish by hand unless that workflow is broken: uploading a version that
the workflow later tries to publish will make it fail.

The manual equivalent, for reference, is:

rem !!!bump version in pyproject.toml first!!!
python -m build
twine upload dist/*
